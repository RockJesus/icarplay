# 应用内一键更新

车机上不方便拔 U 盘、也不方便每次手动传 APK，所以给自己留了一条正规的更新回路：**点一下，查版本、下载、校验、拉起系统安装框**。

`状态：已接入 v0.9.3`　·　`来源 GitHub Releases`　·　`SHA-256 + 签名双校验`　·　[← 返回 README](../README.md)

</div>

---

## 怎么用

1. **首页右上角的版本胶囊**（`v0.9.3`）就是入口，点它进「版本更新」页；
2. 页面打开会自动查一次最新版本，也可以点「检查更新」重查；
3. 有新版本时点 **「一键下载并安装」**：进度条走完 → 自动校验 → 弹出系统安装确认框 → 确认即可；
4. 若提示打不开安装框，点右下角「允许安装」跳到系统的「安装未知应用」开关，给 iCarPlay 打开后再试。

首页还会**每 12 小时静默查一次**：只有真发现新版本时，版本胶囊才会变成绿色 `v0.9.3 ↑ v0.9.4`，不打扰开车。

## 更新链路

| 步骤 | 具体行为 |
|---|---|
| 查版本 | `GET https://api.github.com/repos/RockJesus/icarplay/releases/latest`，读 `tag_name`、`body`、assets 里的 `icarplay.apk` |
| 比版本 | 逐段十进制比较（`0.9.9 → 1.0.0` 算升版），段数不同按缺位 0 处理 |
| 下载 | 直连 Release 资产地址，落到 `Android/data/com.rockjesus.icarplay/files/update/`，边下边报进度 |
| 校验一 | 字节数与 Release 声明的 `size` 不一致 → 删文件、不装 |
| 校验二 | Release 声明 `digest: sha256:…` 时比对摘要，不符 → 删文件、不装 |
| 校验三 | 用 `PackageManager` 比对**下载包签名**与当前已装包签名，不一致 → 删文件、不装（防篡改/防误装他人包） |
| 安装 | `FileProvider` + `ACTION_VIEW`（`application/vnd.android.package-archive`）拉起系统安装确认框 |

## 边界

- **不做静默安装**：不申请 `INSTALL_PACKAGES`，永远由系统确认框收尾；
- **只认自己的 Release**：仓库地址写死在代码里，且必须签名一致才能装；
- 车机没外网时更新页会明确提示连不上，此时仍可用「无线传文件」页让手机传 APK；
- GitHub API 匿名访问有频率限制（每 IP 每小时 60 次），本应用按 12 小时一次自动检查，不会触发；
- 更新不影响车机系统分区，只替换本应用自身。

## 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 检查失败 / 连不上 | 车机没有外网，或网络受限 | 用手机热点给车机联网；或改用「无线传文件」 |
| 按钮灰着 | 已是最新版本 | 无需处理；有新版本会自动亮起 |
| 下载到一半失败 | 断网 / 存储不足 | 清出空间后重试，未完成的 `.part` 会自动丢弃 |
| 校验不通过 | 下载被截断，或包被替换 | 重试一次；仍失败就别装，用传文件页手动传官方 APK |
| 打不开安装框 | 系统没给本应用「安装未知应用」权限 | 点「允许安装」开启后重试 |
