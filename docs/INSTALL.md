# 安装与首次使用（2020 款 SYNC+）

> **安全前提：不要把 iCarPlay 设为默认桌面，也不要随意开启 HiCar 开机自启。**
> 本 APK 不写系统分区、不申请设备管理员；异常处置见 [`SAFETY.md`](SAFETY.md)。

## 1. 准备

- U 盘格式 **FAT32**（不要 exFAT/NTFS）；
- 把 `icarplay-v0.4.6.apk` 放在 U 盘根目录；
- 车机处于能进“安卓原生设置”的状态（输入法漏洞路径）。

## 2. 安装

1. 百度地图 → 搜索框 → 输入法设置 → 更多设置 → 使用帮助 → 隐私政策；
2. 拉到底点百度网址，**关手机蜂窝数据、不关热点**，等报网络错误；
3. 点左上角返回，出现“设置”入口；
4. 安卓原生设置 → 存储 → U 盘 → 点 APK 安装。

### 安装结果判读

| 结果 | 含义 | 下一步 |
|---|---|---|
| 安装成功 | 签名白名单通过 | 继续第 3 步 |
| “应用未安装” | 撞上 SYNC+ 签名墙 | 需要百度签名重签，软件路线在安装这一步断 |
| “解析包错误” | APK 损坏或下载不完整 | 重新拷贝，核对 SHA-256 |
| 按钮灰色/无反应 | 系统禁止未知来源 | 在设置里允许对应来源 |

## 3. 首次启动（桌面没有图标）

装完桌面不会出现第三方图标，用下面任一方式打开一次：

- **设置 → 应用 → iCarPlay → 打开**；
- 或文件管理器里点 APK → “打开”。

进入后：

1. 首次打开 iCarPlay 会自动弹出权限引导：先允许“显示在上层 / 悬浮窗”，再依次允许麦克风、位置、蓝牙、通知（Android 13+）和电池优化；
2. 引导完成后内置小白点默认自动启动；如果手动关掉，可在首页点“小白点：开”重新打开；
3. 屏幕上出现圆形 `iC` 悬浮球，之后不再需要旧的小白点 App。

## 4. 悬浮球

- 拖动：按住移动；
- 点击：弹出面板 —— AirPlay / CarPlay / 认证设置 / 主界面 / 关闭小白点；
- 位置会记住，下次回到原位；
- **默认不注册开机自启**：每次上车需要先打开一次 iCarPlay；打开首页后小白点会自动启动。
  这是故意的，避免 SYNC+ 在 Wi-Fi Direct 模式下进入“黑屏 → LOGO → 黑屏”的重启循环。

## 5. 网络

- AirPlay 要求车机与 iPhone 在**同一局域网**；
- 推荐外接 5GHz 随身路由，车机和 iPhone 都连它；
- SYNC+ 自带热点只支持 2.4G，且 iPhone 经常搜不到，不要作为首选；
- 原车 4G 热点与安卓底层热点是两套网络，不要混用。

## 6. 首次验证清单

- [ ] APK 能装（没有“应用未安装”）
- [ ] 能打开 iCarPlay 主界面
- [ ] 悬浮窗权限能授予
- [ ] 悬浮球能显示、能拖动、能弹面板
- [ ] iPhone 能在控制中心看到 `iCarPlay`
- [ ] AirPlay 镜像能出画面、能出声
- [ ] 关闭小白点后悬浮球消失
