# 安装与首次使用

在 2020 款 SYNC+（Android 8.1 / API 27）上装好 iCarPlay，并完成第一次投屏验证。

`适用版本 v0.9.4`　·　`单 APK`　·　[← 返回 README](../README.md)

</div>

---

> **安全前提**：不要把 iCarPlay 设为默认桌面，也不要随意开启 HiCar 开机自启。
> 本 APK 不写系统分区、不申请设备管理员；异常处置见 [`SAFETY.md`](SAFETY.md)。

## 1. 准备

- U 盘格式 **FAT32**（不要 exFAT / NTFS）；
- 把唯一的 `icarplay.apk` 放在 U 盘根目录；
- 车机处于能进「安卓原生设置」的状态（输入法漏洞路径，见下）。

## 2. 进入原生设置

1. 百度地图 → 搜索框 → 输入法设置 → 更多设置 → 使用帮助 → 隐私政策；
2. 拉到底点百度网址，**关手机蜂窝数据、不关热点**，等报网络错误；
3. 点左上角返回，出现「设置」入口；
4. 安卓原生设置 → 存储 → U 盘 → 点 APK 安装。

## 3. 安装结果判读

| 结果 | 含义 | 下一步 |
|---|---|---|
| 安装成功 | 签名白名单通过 | 继续第 4 步 |
| “应用未安装” | 撞上 SYNC+ 签名墙 | 需要百度签名重签，纯软件路线在安装这一步断 |
| “解析包错误” | APK 损坏或下载不完整 | 重新拷贝，核对 Release 页给出的 SHA-256 |
| 按钮灰色 / 无反应 | 系统禁止未知来源 | 在设置里允许对应来源 |

## 4. 首次启动（桌面没有图标）

装完桌面不会出现第三方图标，用下面任一方式打开一次：

- **设置 → 应用 → iCarPlay → 打开**；
- 或文件管理器里点 APK → “打开”。

进入后：

1. 自动弹出权限引导：先允许「显示在上层 / 悬浮窗」，再依次允许麦克风、位置、蓝牙、通知（Android 13+）和电池优化；
2. 引导完成后**悬浮按钮默认自动启动**，AirPlay 接收随首页一并默认开启；
3. 屏幕上出现紫青渐变圆环的悬浮球，之后不再需要其它悬浮球 App；
4. 若返回原车机桌面后悬浮球被桌面盖住：系统「设置 → 无障碍 → iCarPlay 悬浮按钮」开启。SYNC+ 桌面在系统层，普通悬浮窗压不住它；无障碍悬浮层只绘制悬浮球，不读取屏幕内容。

## 5. 悬浮按钮

| 操作 | 行为 |
|---|---|
| 按住拖动 | 移动位置，松手即记住；越界坐标自动写回，不会跑到可视屏幕外 |
| 单击 | 弹出面板：AirPlay / Android Auto / HiCar / CarPlay / 认证设置 / 系统设置 / iCarPlay 主界面 / 车机主屏幕 |
| 点面板外任何位置 | 面板自动收起，事件不穿透到下层应用 |
| 首页「悬浮按钮：开 / 关」 | 手动开关；关掉后重启不会强制拉起 |
| 车机重启 | **只恢复悬浮球**，不打开主界面，也不自动启动 AirPlay / HiCar 等接收服务 |

仅安装但从未打开过 iCarPlay 时，系统会把新装应用视为“停止状态”，开机广播不会送达；首次安装后需要先打开一次完成权限引导。

## 6. 首页与二级页

首页是车机一屏布局：五张入口卡 + 一行快捷操作 + 一行「返回车机主屏幕」。

| 入口 | 进去做什么 |
|---|---|
| **AirPlay** | 镜像接收已默认开启；iPhone 控制中心「屏幕镜像」选 `iCarPlay` 即可 |
| **CarPlay** | 认证设置与有线 / 无线入口（需 MFi 材料，见 [`CARPLAY.md`](CARPLAY.md)） |
| **CarLife+** | 有线 / 无线连接安卓手机的 CarLife+（见 [`CARLIFE-PLUS.md`](CARLIFE-PLUS.md)） |
| **Android Auto** | USB AOA 有线，或手机 Headunit Server 手动无线（见 [`ANDROID-AUTO.md`](ANDROID-AUTO.md)） |
| **Huawei HiCar** | 华为手机原生 HiCar 实验接收（见 [`HICAR.md`](HICAR.md)） |
| **连接中心** | 网络 / 外设状态、网络体检、mDNS 体检、热点与 AirPlay 开关 |
| **一键无线投屏向导** | 手机开热点 → 车机加入 → 打开接收页，三步走 |
| **DLNA 投送接收** | 手机相册 / 视频 App 选“投屏 · Cast”推音乐、视频、图片 |
| **传文件**（首页快捷操作） | 手机 ⇄ 车机无线互传 APK：开服务→手机浏览器上传 / 下载，蓝牙分享兜底 |

## 7. 网络

- AirPlay 只要求两端在**同一网段**，外网不是必要条件；
- 没有外置路由器时：手机开个人热点让车机加入（首选）；或车机自建热点让手机连（需驱动支持 AP 模式）；或用 USB 线走有线路径；
- iPhone 个人热点建议关掉「最大兼容性」，更容易协商到 5GHz；
- 热点若开了 AP 隔离，iPhone 会搜不到车机，此时用连接中心的「mDNS 体检」确认广播是否可达；
- 原车 4G 热点与安卓底层热点是两套网络，不要混用。

## 8. 首次验证清单

- [ ] APK 能装（没有“应用未安装”）
- [ ] 能打开 iCarPlay 主界面，五张卡同屏、不裁切
- [ ] 悬浮窗权限能授予，悬浮球能显示、能拖动、能弹出面板
- [ ] 面板展开后点空白处能自动收起
- [ ] iPhone 能在控制中心看到 `iCarPlay`，镜像能出画面、能出声
- [ ] 连接中心能读到 SSID / 频段 / IP / 网关，网络体检有结论
- [ ] DLNA 页「启动接收」后，手机能发现设备并投一张图
- [ ] 传文件页「启动服务」后，手机浏览器打开地址能上传一个 APK，并在车机列表里出现
- [ ] 关掉悬浮按钮后悬浮球消失，重启不会自动拉起
